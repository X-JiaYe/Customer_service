# 温湿度传感器节点 TH100 用户指南

## 产品概述

TH100 是一款基于 STM32L0 低功耗主控的无线温湿度采集节点，内置 SHT30 数字温湿度传感器与 LoRa 无线模组，采用 2 节 AA 电池供电，续航可达 2 年以上。适用于仓储、冷链、机房等需要长期无人值守温湿度监测的场合。

## 技术参数

| 项目 | 参数 |
|------|------|
| 主控 | STM32L051 |
| 传感器 | SHT30 数字温湿度一体 |
| 温度量程 | -40℃ ~ +125℃ |
| 温度精度 | ±0.3℃（典型值） |
| 湿度量程 | 0 ~ 100%RH |
| 湿度精度 | ±2%RH（典型值） |
| 无线 | LoRa 470MHz，空旷距离 3km |
| 供电 | 2 节 AA 电池，续航 2 年 |
| 上报周期 | 1 分钟 ~ 24 小时可配 |

## 快速上手

1. 装入 2 节 AA 电池，长按按键 3 秒开机，指示灯常亮 2 秒表示启动成功。
2. 通过配套的上位机软件或网关后台，扫描并添加节点，完成入网配对。
3. 设置上报周期，节点即开始定时采集温湿度并通过 LoRa 上报给网关。
4. 网关将数据通过 MQTT 推送至云平台，即可在 App 或 Web 端查看实时数据。

## 安装注意事项

- 节点应避免安装在阳光直射、风口或强电磁干扰位置。
- 传感器窗口应保持通风，避免灰尘与结露遮挡。
- 若现场需要防爆或防尘外壳，请选用 TH100-IP 防护版本。

## 常见问题

- 数据不上报：检查电池电量与入网状态，确认与网关距离在 LoRa 覆盖范围内。
- 温湿度读数偏差：确认传感器窗口无遮挡，必要时可在云端做单点校准补偿。
