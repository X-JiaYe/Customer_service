# 物联网智能网关 GW200 产品手册

## 产品定位

GW200 是本公司面向工业物联网场景推出的边缘智能网关，主控采用 STM32F407 与 ESP32-S3 双核架构，负责将现场各类传感器、执行器、PLC 设备的数据采集、协议转换与上云。适用于智慧工厂、楼宇能耗监测、农业大棚等场景。

## 核心功能

- 多协议接入：支持 Modbus RTU、RS485、LoRa、Wi-Fi、蓝牙 BLE 多种接入方式，可同时挂载 64 路子设备。
- 边缘计算：内置规则引擎，支持阈值告警、数据滤波、本地联动控制，断网时本地逻辑照常运行。
- 数据上云：支持 MQTT / HTTP 双通道上报，兼容阿里云 IoT、腾讯云 IoT、华为云 IoT 及私有 MQTT Broker。
- 本地存储：板载 8MB SPI Flash，断网期间可缓存最多 10000 条采集记录，网络恢复后断点续传。
- 远程运维：支持 OTA 固件升级、远程参数配置与日志诊断。

## 技术规格

| 项目 | 参数 |
|------|------|
| 主控 | STM32F407 + ESP32-S3 |
| 通信协议 | MQTT、Modbus RTU、LoRa、Wi-Fi、BLE |
| 电源 | DC 9~36V 宽压供电 |
| 功耗 | 平均 1.2W，峰值 3.5W |
| 工作温度 | -40℃ ~ +85℃ |
| 防护等级 | IP30（可选 IP65 外壳） |
| 尺寸 | 95mm × 72mm × 28mm |

## 通信协议支持说明

网关对外统一通过 MQTT 上报数据，默认端口 1883（可配 TLS 8883）。下位机侧支持：
- RS485 总线：Modbus RTU 主站模式，波特率 9600/19200/38400 可配。
- LoRa 无线：与本公司 LoRa 节点配套，空旷距离可达 3km。
- Wi-Fi：2.4GHz，支持 Station / AP 双模式。

## 应用场景

典型应用包括：工厂车间环境监测、配电房温湿度巡检、农业大棚卷帘与灌溉联动控制、楼宇分项能耗计量等。
